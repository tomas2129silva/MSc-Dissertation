# MSc-Dissertation
Correlative imaging of Raman, synchrotron SAXS and nanoindentation on fibrotic tissue with machine learning.

 - Kmeans_SAXS: Generates ground truth data and compares how Kmeans performs when we give it more features
 - HDBSCAN_SAXS: Generates ground truth data with 5 segments and compares how Kmeans performs when we force it 3, 4 and 5 clusters and how HDBSCAN automatically selectes the number of clusters that best fit the data.
